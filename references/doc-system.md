# 文档分层规范（正文/历史两层）

> 本文件是 docs-ops 文档体系契约的唯一事实源；项目特有目录与词形写在项目的
> `docs/doc-contract.json` 数据里，不进入本文。

## 1. 两层判定

| 层 | 放什么 | 判定标准 | 写作时态 |
|---|---|---|---|
| 正文层 | 概念/参考/路线图/集成说明 | **不会过期**的内容：当前机制、当前命令、当前方向 | 现在时；禁日期、轮次、时点计数 |
| 历史层 | 变更记录、决策、基线、已交付快照 | **会过期**的内容：一切带时点的事实 | 过去时；只进不改，修正用追加注记 |

判定口诀：**会过期的进历史，不会过期的进正文**。正文需要交代演变时，只留一句跳转链接。

## 2. 目录契约（默认值，项目用 doc-contract.json 覆盖）

- 正文根：`docs/`；历史层：`docs/history/`；历史索引：`docs/history/README.md`（必须有档案清单表）。
- 正文一级子目录收敛为有限集合（`allowedDirs`），索引文件（`README.md`/`index.md`）豁免。
- `roadmap.md` 只写未来方向；过去时措辞（日期/已交付/本轮/时点）由结构检查拦截。

## 3. 模板契约（assets/templates/）

| 模板 | 用途 | 自带要素 |
|---|---|---|
| body-doc | 概念/机制正文 | 历史跳转位（`$historyPath` 自动计算） |
| roadmap | 未来方向 | 过去时禁令声明 + 历史跳转位 |
| reference-cli | 命令参考 | 退出码约定 + 占位符纪律 |
| history-index | 历史档案索引 | 「只进不改」纪律与登记表 |

## 4. 自带格式规范与可选增强

- docs-ops 拥有：**结构分层**（两层/目录/跳转位）、**写作规则**、**归档流程**、**残留检测**，并**自带通用最小格式规范**：中文优先、可点击引用（相对路径）、kebab-case 命名、表格短值短判定与列数上限。唯一事实源是 `assets/checklists/preflight.md` 的 D 节，四个模板内嵌同一纪律。
- 深度格式 lint（emoji 词表、超宽表格自动检测、类型化模板矩阵）由 `document-governance` **可选提供**，非必需依赖；本 skill 独立即可完成全部宣称职责。
- 两者同时存在时，格式细节以 `document-governance` 为增强口径、结构与残留以本 skill `check` 为准；不存在时本 skill 的最小规范独立成立。
